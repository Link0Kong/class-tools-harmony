# M9 报告 — 课表工具（2026-11-14 第 9 轮）

## 本轮交付

| 模块 | 内容 |
|---|---|
| 模型 | `Course`（day 0=周一、1..12 节、weeks/parity）、`TtSnapshot`、`TtPeriods`（12 节时间表 + 星期标签）、`SessionInfo`、`TtPlan` |
| 解析 | `TtParser`：`site_assets.body` 对象/JSON 字符串双形态；非法课程（day 越界、end<start）丢弃；`meta.termStart` 优先于 `t` |
| 日历 | `TtCalendar`：开学日解析、周次表达式（`1-16,18`、中文分隔符）、`weekOf`、单双周过滤、`sessionsOn`（NEXT/ONGOING/DONE）、`nextSession`（14 天窗口）、`plan`、`roomShort`、节次跨度 |
| 仓库 | `TimetableRepository`：个人课表（`userdata.tt.ttUseMine + ttLocal`）优先 → `site_assets?id=eq.tt` 公共快照；6 小时 TTL；失败回落缓存 |
| UI | `TimetableScreen`：第 N 周 + 周导航（上周/本周/下周）+ 星期切换（默认今天）+ 下一节卡 + 日课程列表（时间/节次/课程/教室/进行中标签）+ 空态 |
| 规模 | 主代码 73 文件 / 11,980 行；测试 18 文件 / 2,670 行；HAP **1,573,916 B**；单测 **216/216** |

## 已知限制（如实）

- **只有日视图**：没有 7 列周视图/时间轴网格（网页是按周网格），移动端优先日视图；周导航 + 星期切换已覆盖查看需求。
- **个人课表登录（教务）未做**：读 `ttLocal` 的链路已就绪（`ttUseMine` 判定 + 解析），但没有登录表单与 `tt_login_enqueue` 轮询。
- 课表为只读，不提供编辑/新增课程。
- 开学日来自快照 `t`=2026-08-31；若教务同步更换学期，需云端刷新（客户端 6h TTL）。
- 节次时间表固定 12 节，与网页/小程序一致；晚课超过 12 节的课程会被丢弃。
