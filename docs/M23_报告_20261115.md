# M23 报告 — 演示在线播放器（分步图 + 原样视频）（2026-11-15 第 23 轮）

## 本轮交付

| 模块 | 内容 |
|---|---|
| 分步图播放 | 详情「在线预览（分步图）」→ 全屏播放器：当前页/步图片（`base + s1-1.webp`，OSS 直链）、顶部 `1 / 16`、左右点按区域切上一步/下一步、跨页自动进位；淡入关闭 |
| 原样播放 | 详情「原样播放（视频）」→ `Video` 组件全屏播放 manifest.video（`deck.mp4`），原生暂停/进度/全屏控件，自动播放 |
| 媒体下载 | 「视频 / 音频单独下载」列表（名称/大小），逐个 `request.downloadFile` 保存到应用沙箱 |
| 解析 | `PptDeckDetail` 扩展：`slides[]`（steps[].img / hasMedia）、`video`（src/w/h/dur/chapters）、`mediaFiles[]`（s/name/size/kind/slides） |
| 修复 | ① manifest.video 用 `s` 字段而非 `src` → 增加 `src → s → path` 回退；② 播放器点按区域盖住头部「关闭」→ 调整 Stack 层序 |
| 规模 | 主代码 106 文件 / 20,657 行；测试 27 文件 / 4,203 行；HAP **2,787,263 B**；单测 **326/326** |

## 模拟器实测

- 分步图：进入「本草孝心」→ 在线预览 → 显示第 1 页（OSS webp 加载成功），点右侧到 `2 / 16`，图片切换正确
- 原样播放：`Video` 播放真实 deck 视频（总长 05:03，播放中 00:05，暂停/进度/全屏控件可用）
- 媒体列表显示两个视频（19.2 MB / 15.1 MB）与下载入口

## 已知限制（如实）

- **上传未做**（`ppt_upload_chunks` 分片上传需要文件选择器 + base64 分片，未实现）。
- 视频章节跳转/倍速/续播未做（仅有原生播放控件）。
- 分步图的媒体热点（热点内嵌播放）未做，按静态图展示。
- 打开已下载文件（调系统应用）未做，仅保存到沙箱并显示路径。
