# M17 报告 — 动效基座（2026-11-15 第 17 轮）

## 背景

用户要求：**把整个 app 完整做完，不能有任何功能或动画或动效缺失**。
本轮先补「全局动效基座」，后续轮次按 `PARITY_BACKLOG.md` 逐工具补功能。

## 本轮交付

| 模块 | 内容 |
|---|---|
| 动效令牌 | `ui/theme/Motion.ets`：快 160 / 常规 260 / 慢 380ms；标准缓动（cubic-bezier .4,0,.2,1）、弹性（spring 0.72/1/220/26）、软弹（0.5/1/200/28）；`pageEnter/pageExit`、`sheetEnter/sheetExit`、`scrim`、`listItem`、`popIn` 转场效果 |
| 底部导航 | 自定义 tab：工作台 / 全部 / 我的（等宽 `layoutWeight`），**液体指示条**（24vp→40vp 拉长 + 弹性吸附到目标 tab），选中字重/颜色渐变，Tabs 内容 260ms 横向滑动 |
| 工具页转场 | `Index` 打开/关闭工具：淡入 + 右侧轻滑 + 0.985 缩放（非对称进出场）；身份页/主壳切换淡入缩放 |
| 导出预览 | `ExportPreview` 入场：20ms 延迟后 260ms 淡入 + 上移 26vp |
| 弹层 | 投票详情/发起、演示详情：遮罩淡入 + 面板自下滑入（asymmetric sheet），关闭走退出动画 |
| 按压反馈 | `ToolTile`：按下缩放 0.97 + 透明度 0.92（160ms），覆盖首页快捷与全部工具卡片 |
| 首屏 | 启动 → 身份 → 主壳的过渡动画 |
