# M22 报告 — 投票全量（指定成员/编辑/延长/倒计时）（2026-11-15 第 22 轮）

## 本轮交付

| 模块 | 内容 |
|---|---|
| 指定成员 | 发起/编辑面板「指定成员」范围：成员名 chips 多选（按座号，无学号）、已选 N 人、清空；`VoteLogic.normalizeSeats`（1–70、去重、升序）+ `validateAudience`（custom 至少 1 人） |
| 编辑投票 | 管理区「编辑」（仅 0 票时显示）：回填标题/说明/选项/规则/可见范围/指定成员，改走 `poll_manage edit`；标题随模式切换「发起投票/编辑投票」 |
| 延长截止 | 管理区「延长」→ 迷你面板（30 分钟/2 小时/1 天 + 新截止预览）→ `poll_manage extend` |
| 倒计时 | 秒级刷新：详情头部显示「截止 11-18 00:00 · 剩 05:23」（<1h 为 `mm:ss`，≥1h 为小时/天） |
| 静默刷新 | 1s 定时器刷新 `now`；详情打开时每 15s 静默 `poll_detail` 刷新数据（人数/结果实时更新），离开页面清理定时器 |
| 动效 | 延长面板滑入/遮罩淡入；编辑/延长按钮按压反馈 |
| 规模 | 主代码 106 文件 / 20,341 行；测试 27 文件 / 4,176 行；HAP **2,742,450 B**；单测 **325/325** |
