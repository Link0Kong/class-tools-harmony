## 本轮修掉的问题

1. **统计三格不刷新**：`@Builder summaryTile(value,label,color)` 值参数不重建 → 改为 `summaryTile(kind)` 内部读 `this.counts()`（与水量/分组同类问题）。
2. `Services.members.refresh` / `league.refresh` 不存在 → 改为 `load(false)`，并补 `ClassMembersResult/ClassLeagueResult` 显式类型。
3. 导出参数误用自定义类 → 改用 `ExportParam`。

## 已知限制（如实）

- **自定义点名名单（`rollSel` 多选）未做**：只有全班/班委/团员三种范围；`rollSel` 字段已能读写但无 UI。
- **无多轮点名/历史记录**：「重置」直接清空当前范围状态（无二次确认）。
- 团员范围依赖 `class_league`（50 人）缓存。
- 导出包含姓名（与网页一致，属班级内部使用；不含学号/手机号/宿舍号）。
