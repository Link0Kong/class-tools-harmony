# M20 报告 — 课表周视图 + 滑周（2026-11-15 第 20 轮）

## 本轮交付

| 模块 | 内容 |
|---|---|
| 周视图 | 7 列 × 12 节网格：左侧节次/时间列，课程块按节次跨行（`(end-start+1)*52`），颜色按课程名哈希取品牌色，块内显示课名 + 短教室；今天所在列淡青底 |
| 切周 | 顶部 `‹ 本周 ›` + 内容区**左右滑动**（PanGesture 40vp 阈值），切周时内容 44vp 滑入回弹（260ms）动画 |
| 课程详情 | 点课程块 → 底部弹层：课名、日期/教室、节次时间、教师、周次/单双周，滑入/关闭动画 |
| 视图切换 | 日 / 周 chips（默认日视图）；周视图保留日期范围 `11-23 ~ 11-29` |
| 入口 | 底部提示「个人课表需在网页/安卓端完成教务登录后同步」+「教务系统」入口（拉起学校 SSO） |
| 数据 | `TtCalendar.coursesOn`（按日过滤周次/单双周 + 节次排序） |
| 规模 | 主代码 105 文件 / 19,771 行；测试 27 文件 / 4,116 行；HAP **2,661,405 B**；单测 **320/320** |

## 模拟器实测

- 第 11 周（无课周）：网格正确留空，日期范围 11-9 ~ 11-15
- 第 13 周：正确渲染 12 门课块（思想道德与法治 1-3 节 01104、C语言 6-7 节 01514、军事理论 3-5 节、高等数学 8-9 节 01217/10-12 节、英语1、计算机、中医学、体育1 等），跨节高度与节次对齐
- 点按顶部 `›` 两次切到第 13 周，无异常

## 已知限制（如实）

- **教务登录未在 HarmonyOS 端实现**：`tt_login_enqueue` 要求 PGP 加密的密码（安卓用第三方 PGP 库），本 App 零第三方依赖且不允许使用真实教务凭据做测试，因此仅提供入口与「个人课表来自网页/安卓同步」的说明；`tt.ttUseMine + ttLocal` 读取链路已就绪（一旦云端有个人课表即显示「我的课表」）。
- 周视图未做整页横向滚动（7 列按屏宽均分，窄屏字号较小）；无课程之间的重叠排布（同一时段多课会重叠，依赖教务数据本身不冲突）。
- 左右滑动切周在网格区域内生效；页面纵向滚动优先。
