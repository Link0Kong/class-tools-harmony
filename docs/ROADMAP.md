# 路线图 — 鸿蒙原生 App

> 原则：**先把基座做对，再按使用频率搬功能**；每个里程碑都必须「可编译 + 有测试 + 能在模拟器上走通」。
> 功能清单与字段口径沿用已有多端实现；数据契约以各端共享的后端契约文档为准。

## M0 骨架（已完成 2026-11-14）

- 工程：DevEco 26 / API 26、hvigor CLI 可构建（`entry-default-unsigned.hap` 约 369 KB）
- 设计令牌：品牌色（雾青/灰蓝/暖沙）、圆角、字号、动效时长
- 数据基座：`HttpClient`（PostgREST 封装：统一头/10s 超时/GET 重试一次/401 清会话）、`ApiResult`
- 身份：`rpc/class_verify` + `Session` + preferences 持久化 + 29 天本地判定
- 外壳：工作台（问候 + 常用工具）/ 全部（按分类）/ 我的（身份卡 + 退出）
- 工具目录：14 个（draw/group/fit/hw/nt/vote/tt/power/ppt/water/roster/roll/diag/jw）+ 占位页
- 验收：CLI 构建成功；未签名 HAP 产出；真机/模拟器运行待签名与镜像下载（见 README）
