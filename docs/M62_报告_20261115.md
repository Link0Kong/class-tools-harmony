## 本轮交付

| 项 | 内容 |
|---|---|
| 估算日耗 | `PowerStats.estimate`：先压成真实变化点，取间隔 ≥1h、下降 >0.05 的段；以中位数（取下中位）算异常阈值 `max(5, 4×median)`，超阈值视为异常扣减并单列 |
| 预计可用 | `daysLeft = q / rate`（保留 1 位小数，rate 下限 0.05） |
| 异常扣减 | 展示「异常扣减 N 次 · X 度（已忽略不计入日耗）」，对应网页 `PW_DEDUCT` |
| 口径统一 | 7 天统计的「日均（度）」改用估算 rate，与「预计可用 X 天 · 日均 Y 度」一致（原来用区间原始下降/小时，会被异常大跌拉偏） |
| 测试 | `estimate_and_deducts`：正常两天 2 度/天、daysLeft 10/2=5、10/3=3.3、除零 0、异常 16 度识别；单测 **343/343** |
