## 本轮修掉的问题

1. **下载一直提示「暂无可下载地址」**：真实 manifest 的文件是 `{s:"compat.pptx", name, size}`（相对名）+ `manifest.base`，不是绝对 `src` → 新增 `resolveUrl/fileUrl` 并按 `base + s` 解析，下载文件名优先用 `name`。
2. **详情缺 id**：`DETAIL_SELECT` 未带 `id`，`parseDeck` 判空导致详情解析失败 → 补 `id` 字段。
3. FakeApi 详情路由按 `select=manifest` 匹配不到新 select → 改为按 `manifest` + `id=eq.` 判定。
4. 测试 JSON 少一个大括号导致「详情 undefined」→ 修正并补 `s/base` 解析用例。

## 已知限制（如实）

- **在线预览/播放未做**（分步图播放器、原样播放视频、续播均无），列表提示「在线预览暂未支持，请下载后打开」。
- **上传未做**（分片上传 `ppt_upload_chunks` 未移植）。
- **打开文件未做**：只保存到应用沙箱，未调系统应用打开/分享（模拟器无 PowerPoint）。
- 单独媒体文件（视频/音频）只显示数量，未提供逐个下载入口。
- 下载无进度条（仅「下载中…」），大文件（37 MB）等待期间无百分比。
