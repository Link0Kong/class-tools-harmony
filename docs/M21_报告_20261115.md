# M21 报告 — 电费趋势交互 + 同期比较 + 慢频估算（2026-11-15 第 21 轮）

## 本轮交付

| 模块 | 内容 |
|---|---|
| 趋势交互 | Canvas `onTouch`：点击/拖动命中最近真实采样点，绘制竖线 + 圆点；右上角气泡显示 `MM-dd HH:mm · xx.xx 度`（松手保留，卡片顶部固定展示，不跟手进图内） |
| 同期比较 | `PowerStats.compare`：24h=今日 0 点至今 vs 昨日同一时段，7d=本周一 vs 上周一同一时段，30d=本月 1 日 vs 上月 1 日同一时段；两窗口都需 ≥2 采样且覆盖 ≥35% 才显示；文案「较昨日/上周/上月同期 ±x% · 上期 x 度」 |
| 慢频估算 | `PowerStats.slowEstimate`：先把网关重复读数压成真实变化点，取间隔 ≥6h 且下降 >0.05 的段，剔除 `max(5, 4×中位)` 异常；1 段标「参考」、多段按时间加权；13/16 号楼 7d/30d 显示「慢频估算 日均 x 度（n 段）」 |
| 扩展取数 | `PowerRepository.loadHistoryWindow`（48h/14d/70d）为比较与慢频估算补历史 |
| 低电通知 | `PowerNotifier`：低电时发本地通知（同电量 6h 内不重复），页面加载时触发 |
| 规模 | 主代码 106 文件 / 20,083 行；测试 27 文件 / 4,168 行；HAP **2,701,309 B**；单测 **324/324** |

- 13号楼324（慢频）：7 天 314 采样，「慢频估算 日均 8.60 度（3 段）」，「较上周同期 +61.3% · 上期 11.25 度」

## 已知限制

- 比较的「上期」按自然周期同等时长截取；数据覆盖不足时只显示「历史数据不足」。
- 慢频估算未做「有效用电段」的充电/扣水特殊识别（用中位数阈值剔除异常）。
- 低电通知需要系统通知权限；模拟器未触发（当前电量 > 阈值），代码路径已实现。
- 趋势图暂未画充值/上升事件的标记点。
