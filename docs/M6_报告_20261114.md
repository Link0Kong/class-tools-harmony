## 本轮修掉的问题

1. **ForEach 用 index 作 key 导致内容不刷新**：清空后评分行仍显示旧数据 → 评分行 key 改为 `name+value+score`；7 个固定输入改为显式渲染（不用 ForEach）。
2. **单项分索引错位**：表单右侧显示的分数整体错一位、长跑显示 `—` → `scoreOfKey` 改为显式映射（h/w→0、vc→1、r50→2、sit→3、jump→4、pull→5、dur→6）。
3. **相册确认框卡死**：`showAssetsCreationDialog` 偶发不弹且 Promise 不返回 → 加 15s 超时 + 「仅保存文件」兜底按钮。

## 已知限制

- 相册确认框在模拟器上不稳定（系统侧），真机需复核；文件兜底始终可用。
- 体测历史改名：数据层已实现（`FitHistory.renameAt`），UI 暂未接改名入口。
- 体测导出卡同样是组件截图（宽 760 逻辑），右侧需横向滑动查看，存图完整。
- 评分表为 2014 国标大学组，未覆盖高中/初中。
