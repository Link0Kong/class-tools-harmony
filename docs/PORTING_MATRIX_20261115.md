> 目的：在动手前逐工具对比 **网页 `web/tools/index.html`**、**安卓 `android-class-tools` v4.55.0** 与
> **鸿蒙 `harmony-class-tools` M76 / 1.0.5**，判定每项能力属于「可完整移植 / 部分缺失 / 不移植」，
> 再按结论实施。本文件先于代码提交（任务要求），实现完成后回填「本轮结论」。
>
> 红线不变：身份门禁、云端契约（`android-class-tools/docs/BACKEND_CONTRACT.md`）、
> 测试只用测试身份/9999 段、隐私不落日志不导出。
> 本轮不接真实账号（学信网/学校统一身份认证均无测试凭据，按页面结构 + 合成样例单测验证）。

## 2. 本轮四项功能的口径与差异

### 2.1 地图（`map`）

- 数据源：ECS H5 `http://121.196.47.2/map/campus_final_25d.html?embed=1`（唯一数据源，不在原生侧重写 canvas）。
- 鸿蒙落点：`ui/tools/MapScreen.ets` + `features/map/MapModels.ets`（纯逻辑：URL/allowlist/加载态文案）。
- 顶栏：返回 / 刷新 / 「浏览器」降级（系统浏览器打开同一 H5）；主文档失败显示重试 + 浏览器打开。
- ⚠️ 已知差异（不影响本轮验收）：安卓的 `AndroidMap.requestLocation()` JS 定位桥未移植，H5 内「我的位置」
  在 App 内可能不可用；如需再补 `javaScriptProxy`（本轮不做，避免为未核实 H5 接口做桥）。
- 明文 HTTP：鸿蒙 API 18+ 默认允许明文（`@ohos.net.networkSecurity` 文档口径），并补充
  `resources/base/profile/network_config.json` 显式放行调试 IP，避免 API 23+ 真机策略差异。

### 2.2 学信网（`chsi`）

- 页面：`my.chsi.com.cn`（档案 wap 首页）、`account.chsi.com.cn`（用户手动登录）、10 个官方工具入口。
- 提取：`runJavaScript` 只读取 `{url,title,text≤6000,links}`（不碰 cookie/localStorage、不发请求），
  按安卓 `ChsiExtractLogic` 口径逐卡片「标题就近取 1–3 行」生成 **4 张数据卡**
  （学籍信息 / 学历信息 / 学位信息 / 在线验证报告）。
- 隐私：展示前掩码 18 位身份证（保留前 6 + 后 4）与 11 位手机号（前 3 + 后 4）；不保存/不上传账号密码。
- 登录态：默认进卡片页（10 入口始终可见），后台加载档案页判断登录态；**绝不自动跳登录页**，
  用户点「去登录/登录学信网」才进官方登录页，登录成功（URL 回档案域 + 页面内容判定）自动回卡片页。
- ⚠️ 部分缺失：数据卡依赖官方页面文本结构，改版/精简页可能提取不到 → 卡片显示空态 + 「打开官方页面查看」；
  真实账号登录未验证（无测试凭据，红线）。

### 2.3 今日校园 / 融合门户（`today`）

- 页面：`https://e.fjtcm.edu.cn/login2`（302 → `authserver.fjtcm.edu.cn/authserver/login`，Apereo CAS；
  登录后 CAS 回跳门户）。12 个服务入口（学工/奖助/勤工/请假/困难/宿舍/心理/一卡通/课表成绩/水电/报修/门户）+ 本地搜索。
- 自动填充：CAS 登录页注入 `<script>` 同款逻辑（显示账号密码区 → `#username`/`#password` 赋值并派发
  `input/change` → 解除 readonly → 检测验证码/滑块（出现则不提交）→ 点 `#login_submit`）；
  账号 = 当前身份 sid，密码 = **本机安全保存的教务密码**（本轮新增 Asset Store 凭据存储，
  与教务登录共用；密码只作为 JS 字面量注入官方页面，不落日志/不上传/不参与同步）。
  同一会话只自动尝试 **1 次**，失败/验证码/无表单 → 回退人工。
- ⚠️ 差异：
  - 「打开今日校园 App」不做（鸿蒙无 Android 包名 Intent；本工具目标是融合门户）。
  - 安卓的 WebVPN/教务深链（`210.34.74.77`）不在本工具范围。
  - 门户子页均为服务端 302 后由用户在官方门户内手动选择（**不伪造业务 URL**，与安卓口径一致）。

### 2.4 文件传输 / 临时云空间（`file`）

- 服务：ECS drop **v2.2** `http://121.196.47.2/drop`（Caddy `/drop/*` → 127.0.0.1:8093），
  鉴权 `X-Device-Id: <班级 token>`（token 只在请求头，不进 URL/日志/落盘）。
- 能力：`/mine`、`/open`、`/state` 增量事件、`/upload/init|chunk|finish`（8 MiB 原始字节分片）、
  `DELETE /file/<id>`、`POST /close`（清空）；单文件/单会话不限大小（仅磁盘限制），
  **逐文件自上传完成起 72h 过期**；签名下载 URL 30 分钟（每次 `/state` 重新签发，403 时刷新重试）。
- 鸿蒙落点：`data/cloudspace/*`（模型/纯逻辑/HTTP 客户端）+ `data/cloudspace/CloudSpaceRepository.ets`
  （`@kit.NetworkKit` + `@kit.CoreFileKit` + `filePicker`）。
- 文件选择：`DocumentViewPicker`（任意类型）→ 读沙箱可访问 URI；下载到应用沙箱
  （`filesDir/cloudspace/<fileId>_<安全名>`）→ `fileUri.getUriFromPath` + `startAbility(viewData)` 打开。
- ⚠️ 差异：安卓落公共 Downloads/SAF，鸿蒙按平台规范落**应用沙箱**（卸载即清除，符合「临时空间」语义）；
  不移植大屏互联的 `text`/`cmd`/`presence`（属大屏功能）。

## 3. 明确不移植的功能与原因

### 3.1 活动（第二课堂）

- 安卓实现：内置 WebView 打开学校 H5 → 用户统一身份登录 → 从页面 `localStorage.lgInfo` 读 token →
  调第二课堂接口拉活动/名额/报名；token 仅本机。
- 不移植原因：① 需要校内统一身份真实账号才能联调（本轮红线：不接真实账号、无测试凭据）；
  ② 安卓侧该功能也未用真实账号验证（见安卓 ROUND62「已知边界」），移植后无法交付可信状态；
  ③ 属独立业务接口（非 CloudBase 契约），超出本轮范围。
- 缺失影响：鸿蒙无活动列表/名额/报名；用户可继续用网页/安卓端。

### 3.2 快递

- 安卓实现：读取本机是否安装拼多多/淘宝/菜鸟/京东 → 用 `Intent`/scheme 深链打开取件码/身份码页；
  未安装回退官方 H5。
- 不移植原因：HarmonyOS 不能按 Android 包名拉起 App，上述平台是否提供鸿蒙客户端/等价 scheme 未核实；
  直接做只能得到一排「打不开」的入口，不如不提供。
- 缺失影响：鸿蒙无快递入口；可在系统浏览器手动访问对应官方 App/网页。

### 3.3 其它

- **统计（管理员）**：网页管理员页，鸿蒙身份模型无对应入口，App 端也无需求（安卓未移植）。
- **大屏互联**：网页大屏专属（drop 的 text/cmd/presence + 遥控协议），鸿蒙无大屏形态。
- **使用说明 / 反馈**：文档型页面；鸿蒙「我的」已给出验收文档与版本信息，不重复建设。
- **OPPO 推送**：Android 厂商通道；鸿蒙使用华为推送（`AppPush` 已有）。
- **安卓专属系统集成**：下载到 Downloads、SAF、Android 定位桥、状态栏沉浸式隐藏——均无鸿蒙等价物或
  按鸿蒙规范改用沙箱/系统能力，不算功能缺失。
