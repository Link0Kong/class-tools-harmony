# M1 报告 — 数据基座（2026-11-14 第 1 轮）

## 本轮交付

| 项 | 内容 |
|---|---|
| 同步 | `UserdataLocalStore`（文件实现 + 内存实现）/ `UserdataRepository`（pull TTL 60s、push 防抖 1200ms、离线补发、v5→v6 迁移、hold 抑制期、开关同步） |

## 验证

1. **本地单测 71/71**（`scripts/test.ps1`）
   - 合并 oracle 3 条 fixture（mp↔web、v5 迁移）
   - `UserdataRepository`：空云端不盲推、远端覆盖、脏 section 抢时间戳、失败→pending→重试成功、无基线跳过、hold 阻断、同步关闭、v5 迁移回写、TTL 跳过网络、water 归一、真实 fixture 全量
   - `MarksRepository`：只收 true、TTL、乐观更新、失败入队与补发、坏响应、坏行跳过
   - 名单：坏行过滤、6h 缓存、失败回落、空数组失败、团员解析、三分类排序/计数/搜索
   - `VisitsReporter`：slot 格式、每小时一次、失败不记、无身份跳过
2. **真实云端契约探针**（`scripts/contract_probe.mjs`，只读、官方测试身份 `3260799999 / 测试账号`）
   - `class_verify` 200，返回 `badge,is_admin,name,ok,role,sid,token`（token 64 位）
   - `userdata` 1 行，`blob` 是 **string**、v6、14 顶层键、`at` 11 键 —— 与解析假设一致
   - `marks` 行键 `id,kind,ref,seat,ts,val` —— 与 `MarkRow` 一致
   - `class_members` 70 行、`badge,is_admin,name,role,seat,sid`，**测试身份已过滤**
   - `class_league` `{ok,count:50,seats:[{name,seat}]}`
3. **写链路探针**（`scripts/contract_write_probe.mjs`，幂等：把当前 blob 原样 upsert 回去）
   - `POST userdata` **200**，`Prefer: return=representation,resolution=merge-duplicates` 可用
   - 回读 blob 仍 v6、键序不变、`homeToolsAt` 不变
