## 本轮修掉的问题

1. **投票编号不合法**：客户端生成 `poll_<ts>_<rand>`，服务端要求 `^p[a-z0-9]{4,32}$` → 改为 `p` + base36(时间) + 随机后缀，并在 `validateDraft` 前置校验（直接调 RPC 得到 `{"ok":false,"reason":"投票编号不合法"}` 定位）。
2. **弹层背景点击关闭吞掉子控件点击**：外层 Column 的 `onClick` 关弹层导致点选项即关闭 → 去掉背景点击关闭，只保留「关闭」。
3. **选项输入框用 ForEach 渲染不生效**：输入后回填丢失 → 改为显式 `optionInput(0..5)` builder（与体测/水量同类问题）。
4. `ui_fill` 脚本在键盘弹出后坐标漂移 → 改为单次 `inputText`（先收键盘再 dump）。

## 已知限制（如实）

- **指定成员范围（custom + 座号多选）未做**：只能全班/班委/团员。
- **选项配图未做**（`img` 字段解析/展示已支持，录入没有选图入口）。
- 编辑（edit）/延长（extend）的 UI 未做，仅「结束投票 / 删除」；`manageBody` 已支持 edit/extend。
- 结果只显示姓名与该选项投票人（匿名投票由服务端不返回姓名）。
- 没有 15s 静默刷新与倒计时秒级跳动（进入/操作时刷新）。
