# M74 报告 — 华为账号绑定与手表免学号登录（2026-11-15）

## 需求

1. 鸿蒙端账号与华为账号绑定；
2. 一个学号最多绑定 **3 个** 不同华为账号；
3. 手表端改为**直接华为账号登录**。

## 服务端（已完成并验证）

新增 `private.hw_bindings` 与 4 个 RPC（SQL 见 `docs/sql/20261115_hw_bindings.sql`）：

| RPC | 作用 |
|---|---|
| `hw_bind(p_open_id, p_device)` | 当前班级 token 绑定华为 openID；超过 3 个拒绝 |
| `hw_login(p_open_id)` | 按 openID 找学号并签发 30 天班级 token（与 class_verify 同构） |
| `hw_bindings()` | 列出当前学号已绑定账号（本人可见） |
| `hw_unbind(p_open_id)` | 解绑本人账号 |

验证（测试身份 3260799999）：

- 连续绑定 3 个 → `{"ok":true,"count":1..3}`
- 第 4 个 → `{"ok":false,"reason":"一个学号最多绑定 3 个华为账号"}`
- `hw_login` → 200，返回 64 位 token，`class_members` 可用
- 解绑 3 个 → 全部 `{"ok":true}`

## 客户端（已编译通过）

- `data/account/HuaweiAccount.ets`：Account Kit 授权，`scopes=['openid']`，直接取 `openID`（**无需服务端换码**）。
- `data/account/AccountBindingRepository.ets`：绑定/列表/解绑/登录封装。
- 手表 `WatchLogin`：主按钮 **华为账号登录**；未绑定提示「请先在手机上绑定」；保留学号+姓名兜底。
- 手机「我的」：新增「华为账号」区块，显示已绑定数量、绑定当前账号、逐条解绑（最多 3 个由服务端强制）。

单测 **347/347**；Debug HAP 3,278,286 B。

## 待验证 / 前置条件

1. AGC 需**开通 Account Kit**（应用服务 → 账号），否则授权接口报未开通；
2. 模拟器/真机需登录华为账号；当前手表模拟器已关闭，未做真机点击验证；
3. 正式安全模型建议后续加：服务端用 authorizationCode 换 openID（当前客户端直传 openID，openID 随机且仅本人可见，风险可接受但非最强）。
