# M40 报告 — 修复上传 owner_sid 缺失（2026-11-15 第 40 轮）

## 问题

`ppt_decks` 表 `owner_sid text NOT NULL DEFAULT ''`，没有 auth 默认值；原实现建行时未写 `owner_sid` → 行归属为空 → RLS `owner_sid = auth_sid()` 必然拒绝，**真实上传会在建行一步失败**。这是契约单测（M39）之后对照 SQL 发现的实际缺陷。

## 修复

| 项 | 内容 |
|---|---|
| 建行字段 | `createDeck` 增加 `owner_sid`、`owner_name`、`client='harmony'`、`source_name`（原文件名）、`progress=0` |
| 身份来源 | 从 `Services.currentSid / currentName` 注入 `PptUploader`（构造参数），UI 不直接拼字段 |
| 测试 | 断言 body 含 `owner_sid/owner_name/client/source_name`；失败路径覆盖 |
| 规模 | 主代码 112 文件 / 21,502 行；测试 27 文件 / 4,359 行；HAP **2,898,250 B**；单测 **336/336** |

## 验证

- 构建成功、336 单测全绿（含 owner 字段断言）
- 真实 E2E 仍受「会写班级共享数据」限制未跑；但阻塞上传的字段级问题已消除
