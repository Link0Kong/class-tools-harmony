# M69 报告 — 系统推送（Push Kit）接入（2026-11-15）

## 已完成（客户端）

| 项 | 内容 |
|---|---|
| 依赖 | `@kit.PushKit`（HMS SDK 自带，无需第三方） |
| 配置 | `module.json5` 增加 `metadata: client_id = 6917621853264955129` |
| 服务封装 | `features/push/AppPush.ets`：`getToken` → 写本人 `userdata.push {token,enabled,at}`；`tokenUpdate` 自动续订；关闭时 `deleteToken` + `enabled=false` |
| 启动 | 登录成功后 `AppPush.syncOnLaunch()`：已开启则静默续订，失败不阻塞 |
| 入口 | 「我的 → 消息推送」开关（默认关），失败提示「推送开通失败，请确认已开通推送服务」 |
| 发送脚本 | `scripts/push_send.mjs`：OAuth client_credentials → Push Kit `messages:send`；支持 `--to` / `--all` / `--watch`（轮询新通知）；凭据只读环境变量 |

## 验证

- Debug 构建成功（HAP 3,164,358 B），单测 **345/345**
- 模拟器：「消息推送」开关渲染正常，点击后提示「已关闭系统推送」/开通失败——**模拟器无 Push Kit 服务，拿不到 token**，属预期

## 还差 3 个外部条件（否则无法真正收到推送）

1. **AGC 开通推送服务**：当前 HDC 应用控制台（应用信息/软件包管理）没有推送入口，需要在 AGC 项目侧开通「推送服务」并确认应用已绑定；开通后 `getToken` 才会返回。
2. **真机验证**：Push token 只能在真实 HarmonyOS 设备上获取；模拟器永远失败。
3. **班级范围发送需要 token 来源**：班级 token 只能读本人 `userdata` 行（实测管理员也只能读自己），所以 `--all` 需要一个 **CloudBase 服务端密钥**（`PUSH_SERVICE_KEY`）来枚举所有 `userdata.push.token`；或者由你在云端加一张 `push_tokens` 表 + 发送 RPC。  
   - 单设备验证可用 `--to <token>` 直接把本人 token 发给自己。
