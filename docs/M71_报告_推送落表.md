# M71 报告 — 推送 token 落表与 1.0.3（2026-11-15）

## 关键发现：不需要服务端密钥

用 PostgREST OpenAPI 根路径检查，云端已有 **`push_tokens` 表**：

- 字段：`id / sid(default auth_sid()) / provider(default oppo) / token / device / app_version / created_at(now()) / updated_at(now())`
- `GET push_tokens` 用 publishable key 即可读（实测 200），发送端无需服务端密钥。

## 本轮改动

| 项 | 内容 |
|---|---|
| Api | 新增 `DELETE`（`Api` 接口、`HttpClient`、`FakeApi`） |
| 客户端 | `AppPush` 拿 token 后：删本人 `provider=harmony` 旧行 → `POST push_tokens`（provider/token/device/app_version）；关闭推送时删除 |
| 发送脚本 | `scripts/push_send.mjs` 的 `--all` 改为读 `push_tokens?provider=eq.harmony`（publishable key），不再需要 `PUSH_SERVICE_KEY` |
| 版本 | **1.0.3 (1000003)** 构建、签名、AGC 上传成功（535,727 B） |
| 回归 | 单测 **345/345** |

## 发送链路验证

- OAuth：200
- Push `validate_only` + 假 token：`80300007`（服务已开通）
- `--all` 读表成功（当前 0 条，输出「没有可发送的 token」）

## 只差真机

1. 手机安装 **1.0.3**（测试版本）
2. 「我的 → 消息推送」打开并允许通知
3. token 进入 `push_tokens`（provider=harmony）
4. 运行 `node scripts/push_send.mjs --all --title 班级通知 --body 测试` 即可全班推送
