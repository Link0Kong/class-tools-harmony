# M11 报告 — 水量工具（2026-11-15 第 11 轮）

## 本轮交付

| 模块 | 内容 |
|---|---|
| 规则 | `WaterRules`：水 3.03 元/吨（无阶梯）、免费 2 吨/人/月、折合扣电 = 水费 ÷ 0.58、4/6 人间、每间 ≤120 条 |
| 模型 | `WaterRecord` / `WaterRoomState` / `WaterState`（深拷贝）/ `WaterCharge` / `WaterMonthStats` / `WaterRecordReview` |
| 编解码 | `WaterCodec`：`{rooms:{<rv>:{p,recs:[{m,r,ts}]}}}` 键序固定；人数非 4/6→4、月份非法/负数/非数丢弃、同月保留最后、升序、≤120；整数读数输出为整数 |
| 计算 | `WaterCalculator`：上一条记录 → 用量/超出/水费/扣电；首条不伪造 0；统计卡（日均、较上月、免费额度）；规则文案 |
| 变更 | `WaterMutator`：录入校验（月份格式、≥0、不得小于上月/大于下一条、同月覆盖需确认）、写入排序、删除、4/6 切换、清空单间 |
| 月份 | `WaterMonth`：`YYYY-MM` 当前/平移（跨年）/当月已过天数/月天数 |
| UI | `WaterScreen`：宿舍选择（未录入/已录入标记）、4/6 人间、月份快捷（上月/本月/下月）+ 月份/读数输入、保存/覆盖确认、统计卡（用量/水费/扣电 + 日均/超出/较上月）、记录列表（用量/水费/删除）、计费规则卡 |
| 规模 | 主代码 83 文件 / 14,149 行；测试 20 文件 / 3,115 行；HAP **1,870,336 B**；单测 **253/253** |

## 本轮修掉的问题

1. **统计三格一直显示「—」**：`@Builder statTile(label, value, unit)` 用值参数，值变化不触发重建 → 改为 `statTile(kind)` 内部读 `this.stats()`（与分组 chip 同一类问题）。
2. 月份切换只能手输：补「上月/本月/下月」快捷，避免文本输入追加问题。

## 已知限制（如实）

- 记录列表只显示最近 12 条（数据保留 120 条，可滚动查看未做分页）。
- 没有导出图片、没有跨月趋势图（网页/小程序也以录入+统计为主）。
- 覆盖确认只用「再点一次保存」，无弹窗。
- 未做「删除整间」入口（数据层 `clearRoom` 已实现）。
