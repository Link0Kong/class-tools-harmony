## 发现的契约漂移（待确认，未改任何端）

`draw` section 的默认值两端不一致：
- 网页 `tools/index.html` `UD_DEF.draw = {}`
- 小程序 `utils/privacy.js` `DEFAULTS.draw = { names: '' }`，oracle `merge_ref.js` 同后者

差异只在「双方都没有 draw section」时体现（合并出 `{}` 还是 `{names:''}`），读取时 `names` 缺省都是空串，
当前不影响功能；但做「逐字节一致」验收时会被判为不一致。鸿蒙端按 **oracle（`{names:''}`）** 实现。
建议后续由网页侧对齐，不在本次任务内改动。
