## 使用路径（真机）

1. 手机安装 1.0.5，用学号+姓名登录；
2. 「我的 → 华为账号 → 绑定」（最多 3 个，服务端强制）；
3. 手表安装 1.0.5，点「华为账号登录」→ 自动换取班级身份；
4. 未绑定时提示“该华为账号尚未绑定学号”，可改用学号进入。
