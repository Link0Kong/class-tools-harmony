## 本轮实测

| 步骤 | 结果 |
|---|---|
| 初始 | 工作台常用工具 3 个（抽签 / 作业 / 通知），`homeTools = ["draw","hw","nt"]` |
| 编辑入口 | 工作台「编辑」→ 显示减号、「添加快捷」；「+」跳转「全部」编辑模式（「点工具加入或移出首页快捷（最多 4 个）」，已选打勾） |
| 添加 | 点「电费」→ 打勾 → 完成 → 工作台出现 4 个（含电费），云端 `homeTools = ["draw","hw","nt","power"]` |
| 移除 | 全部 → 编辑首页 → 点「电费」取消 → 完成 → 恢复 3 个，云端 `homeTools = ["draw","hw","nt"]` |
| 上限 | 提示「最多 4 个」；在 3 个时可直接添加，符合 Web 规则 |
