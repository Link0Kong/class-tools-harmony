## 已知限制

- 导出卡是 ArkUI 组件截图，**不是** Canvas 逐像素实现：与网页/小程序版式「结构、间距、字号一致」，但文字度量/自动两列判定等细节可能不同；成图宽度取决于设备密度与 `scale`（未强制 1520px）。
- 背景渐变用纯色 `#F2F6F4` 代替（避免 ArkTS 渐变元组类型问题），视觉接近。
- 水印文字用「班级工具站」（HarmonyOS 无自有域名）。
- 截图只能截当前可见的卡：`ExportCardView` 在横向 Scroll 内，若节点被裁剪，长卡可能截不全 → 需真机确认；必要时改为「离屏全量渲染 + 分页截图拼接」。
- 抽签 STEP1/STEP2 尚无独立导出（网页规则是工作流每步可导出，后续补）。
- 工具链偶发：同一条命令连跑 `build` + `test` 会出现 hvigor worker 卡死（本机 DevEco 打开时更明显）；
  分开执行即可，本轮已复现两次并确认与代码无关（单跑 test 秒过）。
