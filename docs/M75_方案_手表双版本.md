# M75 方案 — 智能手表版 vs 运动手表版（2026-11-15）

## 结论先说

当前 HAP 是 **HarmonyOS 智能手表版**（ArkUI，可独立联网/登录/推送），**不能安装到运动手表**：
Watch GT 等运动手表运行 **Lite Wearable OS**，应用模型是 JS/ArkTS Lite，与 ArkUI HAP 不兼容。
因此两个版本必须**分开建工程、分开发布**，不是同一个 HAP 里做开关。

| 维度 | 智能手表版（本仓库） | 运动手表版（新建 Lite 工程） |
|---|---|---|
| 系统 | HarmonyOS（Watch 4/5 等） | Lite Wearable OS（Watch GT 等） |
| 技术 | ArkTS/ArkUI，HAP | JS/ArkTS Lite，Lite Wearable 工程 |
| 网络 | 独立 WiFi/eSIM | 无独立网络，依赖手机 |
| 登录 | 华为账号（绑定学号） | 不登录；手机配对后同步 |
| 数据 | 直接调 REST，缓存优先 | 手机端生成快照 → 蓝牙/运动健康同步 |
| 推送 | Push Kit + 手机镜像 | 手机通知镜像 |
| 功能 | 今日/作业/通知/电费 + 操作 | 今日课程、作业数量、通知标题（只读）+「在手机查看」 |
| 发布 | AppGallery（支持设备含手表） | 运动健康 App 市场（Lite 应用） |

## 运动手表版设计

1. **配对**：手机「我的 → 手表同步」生成 6 位码，运动手表输入（或手机扫码绑定设备）。
2. **同步协议**：手机把精简快照 JSON（今日课程/作业数/通知标题，≤2KB）通过蓝牙 GATT 或华为运动健康数据通道写入手表。
3. **刷新**：抬腕/整点拉取；无网时只显示上次快照与「手机未连接」。
4. **不做**：登录、写操作、电费详情、上传。
5. **工程**：`harmony-class-tools-lite/`（DevEco Lite Wearable 模板），需在 SDK Manager 安装 **Lite Wearable SDK**（当前机器未安装）。
