# M63 报告 — 体测历史改名（2026-11-15，第 45 轮）

## 背景

网页体测历史支持「保存/回填/改名/删除」，鸿蒙端此前只有回填/删除。

## 本轮交付

| 项 | 内容 |
|---|---|
| 改名入口 | 历史记录行新增「改名」→ 内联编辑（名称输入 + 保存/取消） |
| 数据写入 | `fitrecs` 行只有 `data` JSON 列，改名通过 `FitCodec.recordToData` 重建 `data.n` 后 `PATCH fitrecs?id=eq.<id>`（不动成绩/时间） |
| 即时刷新 | 本地替换记录名称；`ForEach` key 加入 `record.name`，改名后列表立即更新（修复同 id 不重渲染） |
| 测试 | 新增 `FitRecsRepository` 改名测试（PATCH 路径/`data` 含新名、空 id/空名 no-op、失败路径）；单测 **344/344** |
| 规模 | 主代码 116 文件 / 22,847 行；测试 28 文件 / 4,500 行；HAP **3,103,605 B** |

## 模拟器实测

1. 体测 → 历史记录「体测 11-14 23:36」→「改名」
2. 输入新名保存 → 提示「已改名」，列表显示新名（云端 `data.n` 已更新）
3. 验证后已用脚本把测试记录名恢复为空（显示默认「体测 11-14 23:36」），不留测试痕迹

## 说明

- 名称与成绩存在同一 `data` JSON 里，改名不影响其它字段。
- 空名称按 no-op 处理（不覆盖云端），避免误清空。
