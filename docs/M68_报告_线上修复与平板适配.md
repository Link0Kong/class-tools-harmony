# M68 报告 — 线上登录报错修复 + 平板适配（2026-11-15）

## 线上问题

测试截图：输入学号/姓名后提示 `Could not find the function public.class_verify(e4, f4) in the schema cache`。

## 根因

`entry/obfuscation-rules.txt` 开启了 `-enable-property-obfuscation`。Release 构建把请求体字段
`p_sid` / `p_name` 混淆成 `e4` / `f4`，PostgREST 按字段名找不到 `class_verify(p_sid, p_name)`，
返回 PGRST202。Debug 包未混淆，所以此前模拟器一直正常。

## 修复

1. 关闭 release 属性混淆（同时关闭 top-level / filename / export 混淆，避免同类问题）：
   `entry/obfuscation-rules.txt` 全部注释，保留说明。
2. 登录增加一次自动重试（800ms），把 `schema cache / Could not find the function / PGRST202`
   映射为「登录服务正在更新，请稍后重试」，不再暴露英文数据库错误。
3. 版本升到 **1.0.1 (1000001)**；Release HAP 1,172,272 B；Release APP 签名后 **532,085 B**。

验证：release 产物 `modules.abc` 中 `p_sid` / `p_name` / `class_verify` 均存在（rg 计数 1），
确认不再被改名。
