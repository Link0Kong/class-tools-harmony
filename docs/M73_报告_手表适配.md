# M73 报告 — 手表端适配（第一版，2026-11-15）

## 已实现

| 项 | 内容 |
|---|---|
| 设备 | `module.json5` deviceTypes 增加 **wearable**（同一 HAP，全系列手表） |
| 入口 | `Device.isWearable()` 判断；手表显示 WatchLogin / WatchShell，手机沿用原 UI |
| 手表登录 | `WatchLogin`：圆屏安全区，学号 + 姓名 + 大按钮（44vp） |
| 主界面 | `WatchShell`：4 屏 Swiper（今日 / 作业 / 通知 / 电费），点按刷新、左右滑翻页、振动反馈、底部圆点 |
| 数据 | 复用 `Services`（课表/作业/通知/电费）+ 各仓库 TTL 缓存 |
| 离线 | 所有请求失败时顶部「离线 · 显示缓存」；复杂操作提示「在手机上处理」 |
| 权限 | 增加 `ohos.permission.VIBRATE`（普通权限，无需 AGC 申请） |
| 单测 | `WatchLogic`（倒计时/截止文案/时间/截断/离线）→ **347/347** |
| 构建 | Debug HAP **3,243,390 B** |

## 手机/手表分支

- 手机：`IdentityScreen` + `AppShell`（原逻辑不变，`openTool` 在手表端禁用）
- 手表：`WatchLogin` + `WatchShell`；`ToolScreen` 不会在手表打开
