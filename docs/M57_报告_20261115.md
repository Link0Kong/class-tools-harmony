## 3. 本轮修复的真实缺陷

1. **转换机在线判定错误**：只读 `body.at`，实际字段是 `body.seen_at`（`updated_at` 是旧值）→ 一直显示“离线”。已修 + 单测。
2. **重复下载失败**：目标文件已存在时 `request.downloadFile` 报错 → 下载前 `fs.unlinkSync` 清理旧文件。
3. **`source_ext` 列不存在**：建行 400 → 移除该字段。
4. **时间戳类型错误**：`created_at/updated_at` 是 bigint(ms)，原来发 ISO 字符串 → 400；改为毫秒数。
5. **分片 RLS 缺 owner_sid**：`ppt_upload_chunks` 插入需要 `owner_sid = auth_sid()`，原实现未带 → 401；`putChunk` 增加 owner_sid（App 与契约测试同步）。
6. **软删除被 RLS 拒绝**：PATCH 用 `return=minimal` 返回失败，改 `return=representation` 后 200。
