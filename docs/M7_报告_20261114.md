# M7 报告 — 作业工具（2026-11-14 第 7 轮）

## 本轮交付

| 模块 | 内容 |
|---|---|
| 模型 | `HomeworkRow` / `HomeworkItem`（标题回退正文首行、摘要压缩）/ 附件元信息（不保留 base64） |
| 截止计算 | `HomeworkDueCalculator`：`date`(+`time`) → 本地时间；「还剩 N 小时/天」「已过期 N 小时/天」；tone（URGENT/WARN/SAFE/OVERDUE）；过期 >3 天 `prunable`（仅内存过滤，不写云不删除） |
| 仓库 | `HomeworkRepository`：`GET homework?select=*&order=ts.asc&archived=eq.false`，10 分钟 TTL，失败回落缓存 |
| UI | `HomeworkScreen`：全部/未完成/已完成 三筛（带计数）、卡片（标题/两行摘要/截止/附件数/勾选圈）、点卡片切换完成、刷新、错误与降级提示 |
| 完成状态 | 走 `marks`（kind='hw'）：乐观更新 + 失败待补发 + 提示「稍后自动补发」 |
| 规模 | 主代码 65 文件 / 10,177 行；测试 16 文件 / 2,219 行；HAP **1,322,925 B**；单测 **185/185** |
