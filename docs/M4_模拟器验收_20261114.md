## 3. 本轮实测发现并修掉的问题

1. **P0：`CloudConfig.isConfigured()` 恒假**（表现为登录报「云端配置缺失」）
   - 根因：注入脚本替换 `PUBLISHABLE_KEY` 占位符时，把 `isConfigured()` 里用于比较的占位符字面量一起替换成了真实 key，导致 `key !== key` 恒 false。
   - 修复：改为「长度 > 100 且以 `eyJ` 开头」校验，不做自我比较。
2. **P2：工具卡副标题被截断**（`公平随机 · ...`）→ `maxLines(2)`，两行完整显示。
3. **P2：名单页误导性提示**「当前显示本机缓存」在新鲜缓存时也出现 → 移除。
4. **P2：桌面图标是模板网格图** → `scripts/gen_icons.ps1` 生成品牌三圆点（背景/前景/启动图/app_icon）。
5. **P3：`smoke_emulator.ps1` 重装后首次 `aa start` 偶尔不置前** → 加一次重试 + 等待。
